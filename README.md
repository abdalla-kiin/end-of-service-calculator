# حاسبة مكافأة نهاية الخدمة

حاسبة عربية مجانية لمكافأة نهاية الخدمة حسب نظام العمل السعودي (المواد 84 و85 و87). ملف واحد بدون أي اعتماديات.

## النشر على GitHub Pages
1. أنشئ مستودعاً جديداً على GitHub (Public).
2. ارفع محتويات هذا المجلد في الجذر (index.html و robots.txt و .nojekyll).
3. من Settings ← Pages اختر Branch: main و Folder: / (root) ثم Save.
4. بعد دقيقة يظهر الرابط: https://USERNAME.github.io/REPO/

> الحاسبة تقدير استرشادي وليست استشارة قانونية.
